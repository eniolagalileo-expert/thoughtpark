How I work with AI

  1. One brief, one source of truth. Facts, tokens and rules go in a single file the agent reads before every change.
  2. Build in slices. Lobby before gameplay, one screen before four. Each slice gets opened in a real browser.
  3. Trust nothing until it's clicked. Two tabs playing a full game, screenshots at phone width, a counter that says 494/500.
  4. Ship to a URL. If it isn't live, it isn't done.
